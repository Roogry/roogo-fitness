# Contributing to Roogo Fitness

First off, thank you for considering contributing to Roogo Fitness! We welcome all contributions.

## Getting Started

1. **Read the Docs**: Before you start writing code, please read through our Developer Documentation located in the `docs/` folder, specifically:
   - [Coding Standards](docs/03-coding-standards.md)
   - [Components Guide](docs/05-components-guide.md)
   - [State Management](docs/06-state-management.md)

2. **Branch Naming**: Use a descriptive name for your branch (e.g., `feat/add-new-exercise`, `fix/login-bug`).

3. **Code Style**: Ensure your code follows the established Prettier rules defined in this project.

## Pull Request Process

1. Ensure any install or build dependencies are removed before the end of the layer when doing a build.
2. Update the README.md with details of changes to the interface, this includes new environment variables, exposed ports, useful file locations and container parameters.
3. You may merge the Pull Request in once you have the sign-off of two other developers, or if you do not have permission to do that, you may request the second reviewer to merge it for you.
